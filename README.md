# Sales Performance Analysis Dashboard Using Tableau

## 📊 Project Overview

The **Sales Performance Analysis Dashboard** is a data visualization project developed using Tableau to analyze retail sales, profit, product performance, and regional trends. The project uses the Sample Superstore dataset, which contains fictional retail transaction data.

The goal is to transform raw sales data into meaningful business insights that can help stakeholders understand sales performance, identify profitable product categories, and evaluate regional business performance.

## 🎯 Project Objectives

- Analyze overall sales and profitability.
- Identify top-performing product categories and subcategories.
- Compare sales performance across different regions.
- Understand sales trends over time.
- Evaluate the relationship between sales and profit.
- Present business insights through interactive visualizations.

## 🛠️ Tools and Technologies

- **Tableau Desktop / Tableau Public** — Data visualization and dashboard development
- **Microsoft Excel / CSV** — Dataset storage and preparation
- **GitHub** — Project documentation and version control

## 📁 Dataset

**Dataset:** Sample Superstore

The dataset contains fictional retail transaction records with fields such as:

- Order Date and Ship Date
- Sales and Profit
- Product Category and Subcategory
- Customer and Order Information
- Region, State, and City
- Quantity and Discount

**Data source:** [Kaggle – Sample Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

*Note: The dataset represents sample retail transactions, not the actual sales records of a real company.*

## 📈 Dashboard Features

The dashboard is designed to help users explore retail performance through visual analytics.

- **Sales Analysis:** Understand total sales and changes in sales performance.
- **Profitability Analysis:** Evaluate profit across products and categories.
- **Category Performance:** Compare Furniture, Office Supplies, and Technology.
- **Regional Analysis:** Explore sales performance across geographical regions.
- **Time-Based Analysis:** Examine trends across different dates or periods.
- **Interactive Exploration:** Use available filters and dashboard interactions to explore specific segments.



## 💡 Business Questions Addressed
